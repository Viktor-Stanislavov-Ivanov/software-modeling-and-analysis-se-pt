HiDiveDb

2401322041 Виктор Иванов

University project for the Software Modeling & Analysis course. This repository contains the database design, SQL Server implementation, and Power BI analytics for a custom anime streaming platform.

What's Inside:
1. Diagrams: Conceptual (Chen notation), Logical (Crow's Foot), and the physical Data Warehouse (UML) models.

2. SQL: The HiDiveDb.sql master script. This builds the database across 3 schemas (Accounts, Content, Engagement), sets up functions/procedures/triggers, and seeds the mock data.

3. BI: The Power BI report (.pbix) built on top of the Fact Constellation data warehouse schema.

Setup:
1. Open SQL Server Management Studio (SSMS).

2. Run the HiDiveDb.sql script to create and populate the database.

3. Open the .pbix file in Power BI to view the visualizations.
